          Modules

          New modules start disabled. These controls change local authorization only; they do not provision connectors or cancel external jobs.

            Edit membership

            Changes affect this workspace only. The server preserves the last administrator and checks the loaded revision.

            Use an existing verified directory principal ID, not an email or display name. This does not enroll new identities or give the platform operator access.
